# EXID Crest theme

Gold-emblem profile built from the owner-supplied **EXID GitHub Promo Pack** (15 s film, wide banner, transparent crest).

## Layout

1. **Hero** — the promo film plays once, the transparent crest fades in, glides into the crest slot of the banner and the image stops on the banner (`render_hero.py`). Reduced-motion viewers get the banner frame; the original 1080p MP4 with its soundtrack is linked.
2. **About** — crest, name, role and the Korean introduction.
3. **Tech stack** — Backend / Frontend / AI & Tools plates.
4. **Connect** — GitHub, Repositories and Stars plates (linked).
5. **Activity** — contribution and language panels (dated snapshots; the activity panel links to live stats) and a gold contribution snake (`snake-crest.svg`, generated by the snake workflow).
6. **Featured projects** — four linked repository plates.
7. **Footer** — crest with "CODE · BUILD · SHIP" and the theme switch.

## Design language

Black field with faint gold circuit traces, polished gold bevels with cut corners, wine-red jewels, Cinzel capitals and wide-tracked Montserrat captions — the same vocabulary as the banner. Each panel carries a slow light sweep that is disabled for `prefers-reduced-motion`.

## Building

- `python crest.py` regenerates `assets/crest/*.svg` (Python 3, Pillow, fontTools, brotli). Fonts are embedded as WOFF2 subsets, so panels render identically everywhere; Korean text falls back to the viewer's system font.
- `bash render_crest_hero.sh` rebuilds the hero (ffmpeg, Pillow, numpy).
- `python build_readme.py` renders README.md when `theme.txt` is `crest`. Switch themes with an owner-authored `theme:crest` issue or the workflow's manual dispatch.

Update the snapshot numbers in `crest.py` (`ACTIVITY`, `LANGS`, `SNAPSHOT`) together when refreshing them.
